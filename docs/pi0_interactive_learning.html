    训练流程与推理流程的关键差异

    训练 teacher target known

    真实 actions[B, H, D] 来自数据集
    采样 noise/timenoise ~ N(0,I)，time ~ Beta
    构造 x_t 与 u_tx_t 混合真实动作和噪声，u_t 是监督目标
    prefix + suffix 一次前向完整 attention mask
    MSE(v_t, u_t)先保留 [B,H]，再全局 mean

    推理 generate from noise

    初始高斯噪声x_1 ~ N(0,I)
    prefix KV Cache图像/语言只算一次
    循环跑 suffix每个 denoising step 更新 action tokens
    Euler 更新x_t ← x_t + dt · v_t，dt 为负
    返回 x_0得到 action chunk
    这一页想表达的是：先把 pi0 当成一个“条件向量场预测器”。视觉语言和 state 提供条件，noisy action 是被去噪的对象，模型输出的是把噪声轨迹推向动作轨迹的速度方向。
